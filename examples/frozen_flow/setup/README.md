# Pod setup audit

These are archived setup commands executed on Volt pod uz2ptakxucbe, not a portable installer. The repository path is /volt/code/frozen-flow-study. Execute setup.sh, extras.sh and assets.sh with setsid -f and log redirection to survive disconnects; setup installs the locked inference environment, then Python3.8 simulator dependencies and official checkpoint. extras installs CPU rendering system libraries and remaining simulator dependencies. assets downloads the pinned benchmark asset archive and extracts it. configure_runtime.py writes distinct LIBERO_CONFIG_PATH directories; runtime.json gives exact runtime variables. hash_checkpoint.sh records full checkpoint SHA256s and the historical metadata identity. No setup step evaluates a policy or trains anything.

setup.sh initially used nohup, which did not survive the initial connect exit; setsid was verified. Installing robomimic with full dependencies initially failed building egl-probe; extras.sh installs required rendering libraries and robomimic --no-deps because simulator import uses only its APIs. Simulator imports verified with explicit PYTHONPATH, CPU osmesa, and CUDA_VISIBLE_DEVICES empty. See dependency freezes. Actual rollout smoke and GPU sampler parity are separate validation stages.
