## Matched execution and scoring

Action horizon10, model actiondim32, transformed actiondim7, execute5 then replan, batch1. Render256, resize/pad224, rotateimages180degrees, 10 stabilization dummy steps; existing official success check. Max policy actions: spatial220, object280, goal300, long520. Production preprocessing and checkpoint are fixed. Noise uses SHA256-keyed NumPy float32 standard normal(10,32) from benchmark/suite/task/seed/state/chunk, excludes arm. Every arm shares initial state, stabilization hash, first observation and first noise; whole conditions stay on one verified GPU. Fixed1/10 arm order alternates deterministically.

The existing cached fixed trace returns the first velocity evaluation's features for the frozen head. Initial log-sigma and sigma are logged without another pi0.5 evaluation; head overhead is separately recorded and included in scored-policy latency for all arms. Sigma never changes actions or rule allocation. Preparation compares instrumented actions with uninstrumented production policy at both arms; initial log-sigma equality tolerance1e-6 for paired initial observation/noise. Direct-rule smoke must reproduce matching fixed-arm actions, outcomes and counted evaluations. All scored chunks report velocity evaluations, reference evaluations (zero), head evaluations, latency and action hashes.

Primary sigma analysis uses first chunk of the episode only. Higher initial log-sigma is predeclared to rank rescues above regressions; no sign reversal. Report AUROC overall and within type; require at least10rescues,10regressions and5conditions for each credible ranking claim. Missing classes -> undefined AUC; otherwise smaller samples remain descriptive. This conditional rescue-versus-regression ranking is not proof of prospective intervention utility across all episodes.

## Comparisons, uncertainty and decisions

Derive rule outcomes and costs from each case's declared fixed arm. Compare rule with fixed1 and fixed10; separately count fixed10 rescues and regressions vs1 by perturbation type. Report 10,000-draw paired condition-cluster percentile95% intervals, retaining all cases/arms, seed20261003; family-cluster sensitivity is required. Report invalid one-class AUC bootstrap draws.

Positive selective-allocation evidence requires rule-minus-fixed10 success lower95% condition-cluster bound >=0 AND rule-minus-fixed10 per-case mean scored-policy-call latency upper95% bound <0. This is a conservative support criterion, not a conventional noninferiority test with a margin and not a joint95% confidence guarantee. Intervals crossing zero are inconclusive; failure to reject a difference does not establish equivalence. Velocity evaluations/chunk and per episode, head time, total policy time and simulator-inclusive episode latency are separate.

No costs of an undeveloped deployable metadata classifier are assumed. No adaptive speedup claim. If independent sigma ranking supports rescue discrimination, recommend a separate test of the existing head as controller; otherwise state missing evidence without fitting/tuning on this test set.
